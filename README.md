# super-guide

Ad Link Editor - A browser-based advertisement content editor.

## Features

- Rich text editing
- Bold, italic and underline
- Heading and paragraph
- Bullet lists
- Hyperlink insertion
- Image URL insertion
- Image upload
- Live preview
- Browser local storage
- Export HTML

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Run locally

Open index.html in your browser.

## Deployment

This project can be deployed directly to Vercel.

Framework Preset: Other
Build Command: Blank
Output Directory: .
